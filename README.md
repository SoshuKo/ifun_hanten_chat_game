# イーフン飯店 会話ゲーム

## 起動
ZIPを展開し、`index.html` をブラウザで開いてください。外部サーバーやインターネット接続は不要です。

## 操作
- 移動: 画面の十字キー / WASD / 矢印キー
- 話す: 画面の「話す」 / E / Enter / Space
- キャラクター召喚・削除: 右上ボタン / M / C
- 閉じる: × / Esc
- 表示倍率: 右上の − / ＋

## 仕様
- プレイヤー以外の54キャラクターを召喚/削除できます。
- 1キャラクターにつき1人まで。
- モンはイーフン飯店の店員として初期配置されていますが、削除可能です。
- キャラクターの近くで「話す」と、付属の会話データ5行を順番に切り替えて会話できます。
- 通行判定は付属の緑/白マスクから作成した内蔵ビットマスクを使用します。そのため file:// で直接開いても動作します。
- NPCは現在、召喚位置で静止し、近くにプレイヤーが来ると向きを変えます。
- キャラクター画像は全12コマを同梱しています。プレイヤーは歩行アニメーションを使用します。

## データ
- `data/ifun_54_dialogues.json`: 元会話データ
- `assets/map/ifun_hanten.png`: 店内マップ
- `assets/map/ifun_hanten_walkmask.png`: 元通行判定マスク（ゲーム本体は `js/collision.js` の内蔵データを使用）
- `assets/characters/`: 55キャラクター（プレイヤー含む）の12コマ画像

## 補足
キャラクター名は「ガニミード」表記で統一しています。
